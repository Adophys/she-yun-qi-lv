# 畲韵奇旅 - 数据库设计 V1.0

## 1. 数据库选型

- PostgreSQL 16
- SQLAlchemy 2 async ORM
- 所有表继承 UUID 主键 + 时间戳 + 乐观锁

## 2. 实体关系

```
User ||--o{ UserExploreProgress : 拥有
User ||--o{ UserCollection : 收集
User ||--o{ UserWardrobe : 拥有
User ||--o{ UserAchievement : 获得
Chapter ||--o{ ExploreNode : 包含
ExploreNode ||--o{ UserExploreProgress : 被挑战
CulturalItem ||--o{ UserCollection : 被收集
WardrobeItem ||--o{ UserWardrobe : 被穿戴
Achievement ||--o{ UserAchievement : 被获得
```

## 4. 枚举定义

### CulturalCategory

- `clothing` 服饰
- `pattern` 纹样
- `music` 音乐
- `cuisine` 饮食
- `craft` 工艺

### Rarity

- `common` 普通
- `rare` 稀有
- `legendary` 传世

### WardrobeCategory

- `clothes` 服饰
- `headwear` 头饰
- `accessories` 配饰
- `skins` 皮肤

### OrderStatus（订单状态）

```
pending_payment → paid → shipped → completed
       ↓                      ↓
  cancelled(超时/用户取消)   refunded（部分/全额）
```

- `pending_payment` 待付款（下单即建，30 分钟过期）
- `paid` 已支付/待发货
- `shipped` 已发货/待收货
- `completed` 已完成（确认收货）
- `cancelled` 已取消
- `refunding` 退款中
- `refunded` 已退款

### PayStatus（支付流水状态）

- `pending` 待支付
- `success` 支付成功
- `failed` 支付失败/已关闭
- `refunded` 已退款

### ProductStatus（商品状态）

- `draft` 草稿
- `on_sale` 在售
- `off_sale` 下架
