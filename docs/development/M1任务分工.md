# M1 任务分工（第 1-3 周 · MVP）

> 依据《需求分析_V1.0》M1 范围：登录、主页、二维码扫描、图鉴收藏、管理端图鉴/点位管理、商城页面骨架。
> 接口以《接口契约_V1.0》为唯一依据；数据库以《数据库设计_V1.0》为唯一依据。有异议先在群里提，改文档再写码。

## 开工前准备（每人必做，第 1 天）

1. `git clone https://github.com/Adophys/she-yun-qi-lv.git && cd she-yun-qi-lv`
2. `git checkout develop`，日常开发从 develop 拉 `feature/xxx` 分支
3. 阅读根目录 README + `docs/requirements/需求分析_V1.0.md` + 自己端的实施指南
4. 各端先跑通本地环境（各子目录 README 有说明）

## 协作规则（重要）

1. **先文档后代码**：接口要改？先改《接口契约》发群里确认，再动手。
2. **feature 分支 + PR**：`feature/xxx` → PR 到 `develop`，标题写清楚 `feat(scope): xxx`，描述里关联任务号（如 B3）。
3. **每天下班前 push**：哪怕没写完，push 到自己的 feature 分支，方便互相看进度。
4. **卡住超过 2 小时就在群里喊**，别自己闷头耗。
5. 密钥/AppID 一律放 `.env`（参考各端 `.env.example`），**严禁提交真实密钥**。
