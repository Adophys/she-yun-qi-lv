# 畲韵奇旅 - 接口契约 V1.0

## 1. 统一响应格式

```json
{
  "code": "SUCCESS",
  "message": "ok",
  "data": {},
  "requestId": "uuid",
  "serverTime": "2026-08-18T14:00:00+08:00"
}
```

- `code == "SUCCESS"` 表示业务成功
- 业务失败时 `code != "SUCCESS"`，HTTP 状态码通常为 200 或 400

## 2. 接口前缀

| 用途 | 前缀 |
|---|---|
| 健康检查 | `/health/live`, `/health/ready` |
| 小程序 | `/api/v1/app` |
| 管理端 | `/api/v1/admin` |

## 3. 认证

### 小程序

```
POST /api/v1/app/auth/wx-login
Body: { "code": "wx_login_code" }
Response: { "accessToken": "...", "refreshToken": "...", "expiresIn": 1800 }
```

后续请求 header：`Authorization: Bearer <accessToken>`

### 管理端

```
POST /api/v1/admin/auth/login
Body: { "username": "...", "password": "..." }
Response: HttpOnly cookie refresh + { "accessToken": "...", "expiresIn": 1800 }
```

收货地址：

订单与支付：

```
POST /api/v1/app/shop/orders
Body: {
  "items": [ { "skuId", "quantity" } ],
  "addressId": "uuid",
  "remark": ""
}
Response: {
  "orderId", "orderNo", "payAmount", "expiredAt",
  "payment": { "timeStamp", "nonceStr", "package", "signType", "paySign" }  // 直接透传 wx.requestPayment
}

GET  /api/v1/app/shop/orders?status=&page=&pageSize=
Response: { "items": [ { "orderId", "orderNo", "status", "payAmount", "items", "shipment", "createdAt" } ], "total" }

GET  /api/v1/app/shop/orders/:orderId
POST /api/v1/app/shop/orders/:orderId/cancel       # 仅待付款可取消
POST /api/v1/app/shop/orders/:orderId/confirm      # 确认收货（shipped → completed）
POST /api/v1/app/shop/orders/:orderId/refund       # 用户申请退款（可选，也可仅管理端发起）
```

微信支付回调（无鉴权，微信服务器调用，需验签）：

```
POST /api/v1/app/shop/pay/notify     # 支付结果通知（APIv3, 证书验签 + 解密）
POST /api/v1/app/shop/refund/notify  # 退款结果通知
```

后端回调处理要求：验签 → 解密校验 `order_no` 与金额 → 幂等更新订单/支付流水 → 扣减预占库存 → 返回 `{"code":"SUCCESS"}`。

## 5. 错误码

| 错误码 | 说明 |
|---|---|
| `SUCCESS` | 成功 |
| `AUTH_INVALID_CREDENTIALS` | 用户名或密码错误 |
| `AUTH_TOKEN_EXPIRED` | Token 已过期 |
| `AUTH_UNAUTHORIZED` | 未授权 |
| `CULTURAL_ITEM_NOT_FOUND` | 文化条目不存在 |
| `EXPLORE_NODE_LOCKED` | 节点未解锁 |
| `WARDROBE_NOT_ENOUGH_FRAGMENTS` | 碎片不足 |
| `SHOP_PRODUCT_NOT_FOUND` | 商品不存在或已下架 |
| `SHOP_SKU_OUT_OF_STOCK` | 库存不足 |
| `SHOP_CART_SKU_NOT_FOUND` | 购物车条目不存在 |
| `SHOP_ADDRESS_NOT_FOUND` | 收货地址不存在 |
| `SHOP_ORDER_NOT_FOUND` | 订单不存在 |
| `SHOP_ORDER_STATUS_INVALID` | 订单状态不允许该操作（如已支付不可取消） |
| `SHOP_PAYMENT_DISABLED` | 支付功能未开通（feature flag 关闭，提示走意向收集） |
| `SHOP_REFUND_AMOUNT_EXCEEDED` | 退款金额超出可退金额 |

## 6. 微信支付配置项（方案 A）

后端环境变量（加入 `backend/.env`，切勿提交真实密钥）：

```
WECHAT_PAY_MCHID=1900000000            # 商户号
WECHAT_PAY_APPID=wx1234567890          # 小程序 AppID（与商户号绑定）
WECHAT_PAY_API_V3_KEY=xxxx             # APIv3 密钥
WECHAT_PAY_SERIAL_NO=xxxx              # 商户证书序列号
WECHAT_PAY_PRIVATE_KEY_PATH=/secrets/apiclient_key.pem
WECHAT_PAY_NOTIFY_URL=https://api.example.com/api/v1/app/shop/pay/notify
SHOP_PAYMENT_ENABLED=true              # feature flag：资质未办齐时置 false 降级
```

时序要点：
1. 下单接口服务端计算金额（**绝不信客户端价格**），创建订单 + 库存预占 + 调用微信 `v3/pay/transactions/jsapi`；
2. 小程序端拿返回参数直接调 `wx.requestPayment`；
3. 支付成功以**异步回调为准**（前端成功回调仅作跳转提示），回调验签失败返回 4xx 让微信重试；
4. 支付超时：延迟任务（30 分钟）校验订单未支付 → 关闭订单 + 释放库存 + 调微信关单接口。
