# 畲韵奇旅 - 接口契约 V1.0

## 1. 统一响应格式

```json
{
  "code": "SUCCESS",
  "message": "ok",
  "data": {},
  "requestId": "uuid",
  "serverTime": "2026-08-18T14:00:00+08:00"
}
```

- `code == "SUCCESS"` 表示业务成功
- 业务失败时 `code != "SUCCESS"`，HTTP 状态码通常为 200 或 400

## 2. 接口前缀

| 用途 | 前缀 |
|---|---|
| 健康检查 | `/health/live`, `/health/ready` |
| 小程序 | `/api/v1/app` |
| 管理端 | `/api/v1/admin` |

## 3. 认证

### 小程序

```
POST /api/v1/app/auth/wx-login
Body: { "code": "wx_login_code" }
Response: { "accessToken": "...", "refreshToken": "...", "expiresIn": 1800 }
```

后续请求 header：`Authorization: Bearer <accessToken>`

### 管理端

```
POST /api/v1/admin/auth/login
Body: { "username": "...", "password": "..." }
Response: HttpOnly cookie refresh + { "accessToken": "...", "expiresIn": 1800 }
```

## 4. 核心接口

### 4.1 小程序

#### 首页

```
GET /api/v1/app/home/summary
Response: {
  "dailyTask": { ... },
  "chapterProgress": { ... },
  "user": { ... }
}
```

#### 探索节点

```
GET /api/v1/app/explore-nodes
Response: [ { "id", "name", "status", "stars", "chapter" } ]

GET /api/v1/app/explore-nodes/:id
Response: { "id", "name", "description", "puzzleImageUrl", "puzzlePieces" }

POST /api/v1/app/explore-nodes/:id/complete
Response: { "gainedPoints", "gainedFragment" }
```

#### 文化图鉴

```
GET /api/v1/app/cultural-items?category=
Response: [ { "id", "name", "category", "rarity", "imageUrl", "isDiscovered" } ]

GET /api/v1/app/cultural-items/:id
Response: { 完整详情 }
```

#### 衣橱

```
GET /api/v1/app/wardrobe
Response: [ { "id", "name", "category", "fragments", "totalFragments", "isEquipped" } ]

POST /api/v1/app/wardrobe/:id/equip
POST /api/v1/app/wardrobe/:id/craft
```

#### 扫描

```
POST /api/v1/app/scan/recognize
Body: { "code": "nfc_or_ar_code" }
Response: { "matchedItemId", "gainedPoints" }
```

### 4.2 管理端

```
GET    /api/v1/admin/dashboard/summary
GET    /api/v1/admin/cultural-items
POST   /api/v1/admin/cultural-items
PUT    /api/v1/admin/cultural-items/:id
DELETE /api/v1/admin/cultural-items/:id

GET    /api/v1/admin/explore-nodes
POST   /api/v1/admin/explore-nodes
PUT    /api/v1/admin/explore-nodes/:id

GET    /api/v1/admin/users
GET    /api/v1/admin/users/:id
```

## 5. 错误码

| 错误码 | 说明 |
|---|---|
| `SUCCESS` | 成功 |
| `AUTH_INVALID_CREDENTIALS` | 用户名或密码错误 |
| `AUTH_TOKEN_EXPIRED` | Token 已过期 |
| `AUTH_UNAUTHORIZED` | 未授权 |
| `CULTURAL_ITEM_NOT_FOUND` | 文化条目不存在 |
| `EXPLORE_NODE_LOCKED` | 节点未解锁 |
| `WARDROBE_NOT_ENOUGH_FRAGMENTS` | 碎片不足 |
