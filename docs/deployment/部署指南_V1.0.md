# 部署指南 V1.0

## 1. 本地开发

```bash
# 项目根目录
cp .env.example .env
docker compose up -d

cd backend
cp .env.example .env
uv sync
uv run python -m app.commands.init_db
uv run python -m app.commands.seed_demo_data
uv run uvicorn app.main:app --reload
```

## 2. 生产部署

### 2.1 准备环境变量

```bash
cp .env.production.example .env.production
# 编辑 .env.production，设置 DATABASE_URL、JWT secrets、INITIAL_ADMIN_PASSWORD 等
```

### 2.2 启动服务

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --build
```

### 2.3 服务组成

- `postgres`: PostgreSQL 数据库
- `db-init`: 一次性初始化数据库与管理员
- `backend`: FastAPI 服务
- `nginx`: 静态资源 + 反向代理

## 3. 微信小程序发布

1. 在 `miniapp/uni-app/manifest.json` 中配置正式 `appid`
2. 执行 `npm run build:mp-weixin`
3. 微信开发者工具上传代码
4. 在微信公众平台提交审核

## 4. 管理端发布

1. 执行 `pnpm build`
2. 将 `frontend/dist` 部署到 Nginx 静态目录
