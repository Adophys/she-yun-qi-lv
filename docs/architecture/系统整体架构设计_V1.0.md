# 畲韵奇旅 - 系统整体架构设计 V1.0

## 1. 项目概述

畲韵奇旅是一款面向大学生的畲族文化数字化体验微信小程序，通过游戏化探索、AR/NFC 扫描、文化图鉴、IP 换装、纹样拼图等互动形式，让用户在移动端沉浸式学习畲族文化。

## 2. 业务目标

- 打造高校双创赛可落地的文化科普小程序
- 建立可持续运营的内容管理体系
- 为三位协作者提供清晰的分工边界

## 4. 子系统划分

### 4.1 小程序 (miniapp/uni-app/)

- 技术栈：uni-app 3.0 + Vue 3
- 目标平台：微信小程序
- 核心页面：村落、探索、扫描、收藏、我的、衣橱、拼图、详情、设置、登录

### 4.2 管理端 (frontend/)

- 技术栈：Vue 3 + TypeScript + Vite
- 核心功能：内容管理（文化条目、章节关卡）、用户管理、数据统计

### 4.3 后端 (backend/)

- 技术栈：FastAPI + SQLAlchemy 2 (async) + PostgreSQL
- 核心模块：认证、用户、文化图鉴、章节探索、衣橱、成就、扫描记录

## 6. 核心数据流

1. 用户打开小程序 → 微信登录获取 code → 后端换取 token
2. 用户探索关卡 → 解锁拼图 → 完成挑战 → 获得积分与碎片
3. 用户 AR/NFC 扫描 → 识别文化符号 → 解锁图鉴卡片
4. 运营人员在管理端编辑内容 → 保存到后端 → 小程序刷新可见

## 7. 接口版本

- 基础路径：`/api/v1`
- 小程序前缀：`/api/v1/app`
- 管理端前缀：`/api/v1/admin`
- 健康检查：`/health/live`, `/health/ready`

## 8. 安全

- 双域 JWT：小程序与管理端使用不同的 secret/issuer/audience
- 小程序：微信 code 换 token，access token 存本地 storage
- 管理端：账号密码 + HttpOnly refresh cookie
- 生产环境强制 HTTPS

## 9. 部署

- 本地开发：Docker Compose 启动 PostgreSQL
- 生产环境：Docker Compose 部署 PostgreSQL + FastAPI + Nginx
