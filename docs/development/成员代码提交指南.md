# 成员代码提交指南（手把手版）

> 写给 @web-demo-lab（管理端）和 @mute-sheep（小程序）。
> 不需要记住 Git 的所有概念，照着复制粘贴命令即可。

---

## 第 0 步：确认你有仓库权限

仓库地址：https://github.com/Adophys/she-yun-qi-lv

1. 用浏览器打开上面的地址。
2. 如果能打开并且右上角没有提示无权限 → 你是协作者，继续。
3. 如果提示 404 或无权限 → 微信告诉小陈，他会发邀请邮件到你的 GitHub 注册邮箱，
   **去邮箱点接受邀请**（或打开 https://github.com/Adophys/she-yun-qi-lv/invitations ）。

---

## 第 1 步：克隆仓库到本地（只需做一次）

电脑上需装好 Git（https://git-scm.com/downloads ，一路下一步）。

在你想放代码的文件夹右键 → **Git Bash Here**，执行：

```bash
git clone https://github.com/Adophys/she-yun-qi-lv.git
cd she-yun-qi-lv
```

> 如果弹窗要求登录，选 **Sign in with your browser**，用你的 GitHub 账号授权即可。

---

## 第 2 步：把你的代码放进来

**情况 A：代码已经写好了（在别的文件夹里）**

把你写好的文件复制到仓库对应目录里：

- 管理端（Vue 3）→ 覆盖到 `frontend/` 目录
- 小程序（uni-app）→ 覆盖到 `miniapp/uni-app/` 目录

> 注意：`node_modules/`、`dist/`、`unpackage/` 这些文件夹**不要复制**（又大又没用，仓库会自动忽略）。

**情况 B：代码还没写 / 直接在克隆的仓库里开发**

直接在对应目录里写就行。

---

## 第 3 步：提交并推送

每次写完一波代码，在仓库根目录（`she-yun-qi-lv/`）打开 Git Bash：

```bash
# 1. 建一个自己的分支（名字按你的功能改，只第一次需要）
git checkout -b feature/admin-pages

# 2. 查看你改了哪些文件
git status

# 3. 把你的改动全部加入提交
git add .

# 4. 提交（描述写清楚做了什么）
git commit -m "feat(frontend): 管理端登录页和图鉴管理页"

# 5. 推送到 GitHub（第一次推这个分支要加 -u）
git push -u origin feature/admin-pages

# 以后再推同一分支，只需要：
git add .
git commit -m "feat(frontend): xxx"
git push
```

推送完**微信告诉小陈一声**，由他负责合并进 develop/main。

---

## 不想敲命令？用 VS Code 也行

1. 用 VS Code 打开 `she-yun-qi-lv` 文件夹。
2. 左侧第三个图标（源代码管理）：
   - 改动的文件点 **+**（暂存）
   - 上方输入框写提交描述 → 点 **✓ 提交**
   - 点 **同步更改 / Sync Changes** 即推送
3. 右下角状态栏可以点分支名 → **创建新分支**。

---

## 常见问题

| 问题 | 解决 |
|---|---|
| push 报 `403` / `permission denied` | 你还没接受协作者邀请，见第 0 步 |
| push 报 `non-fast-forward` / 被拒绝 | 有人先推了新代码。执行 `git pull origin 你的分支名` 后再 push |
| `LF will be replaced by CRLF` 警告 | 无害，忽略即可 |
| 推错分支了 | 不用慌，微信告诉小陈处理 |
| 想撤销某次提交 | 别自己折腾，微信告诉小陈 |

## 分支命名速查

- 新功能：`feature/admin-pages`、`feature/miniapp-scan`
- 修 Bug：`fix/login-redirect`

## 提交信息格式

`类型(范围): 做了什么`，例如：

- `feat(frontend): 图鉴管理页增删改查`
- `feat(miniapp): 扫码解锁页面`
- `fix(miniapp): 修复登录 token 失效未跳转`
