# 畲韵奇旅 - 数据库设计 V1.0

## 1. 数据库选型

- PostgreSQL 16
- SQLAlchemy 2 async ORM
- 所有表继承 UUID 主键 + 时间戳 + 乐观锁

## 2. 实体关系

```
User ||--o{ UserExploreProgress : 拥有
User ||--o{ UserCollection : 收集
User ||--o{ UserWardrobe : 拥有
User ||--o{ UserAchievement : 获得
Chapter ||--o{ ExploreNode : 包含
ExploreNode ||--o{ UserExploreProgress : 被挑战
CulturalItem ||--o{ UserCollection : 被收集
WardrobeItem ||--o{ UserWardrobe : 被穿戴
Achievement ||--o{ UserAchievement : 被获得
```

## 3. 表设计

### 3.1 user（用户）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID | 主键 |
| openid | VARCHAR(64) | 微信 openid |
| phone | VARCHAR(20) | 手机号 |
| nickname | VARCHAR(64) | 昵称 |
| avatar_url | VARCHAR(512) | 头像 |
| level | INT | 等级 |
| title | VARCHAR(64) | 称号 |
| points | INT | 积分 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

### 3.2 admin_user（管理员）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID | 主键 |
| username | VARCHAR(64) | 用户名 |
| hashed_password | VARCHAR(255) | 密码哈希 |
| is_active | BOOLEAN | 是否启用 |

### 3.3 chapter（章节）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID | 主键 |
| name | VARCHAR(128) | 章节名 |
| description | TEXT | 介绍 |
| sort_order | INT | 排序 |

### 3.4 explore_node（探索节点）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID | 主键 |
| chapter_id | UUID | 章节 ID |
| name | VARCHAR(128) | 节点名 |
| location | VARCHAR(255) | 地点 |
| description | TEXT | 介绍 |
| preview_image_url | VARCHAR(512) | 预览图 |
| puzzle_image_url | VARCHAR(512) | 拼图底图 |
| puzzle_pieces | INT | 拼图块数 |
| sort_order | INT | 排序 |

### 3.5 cultural_item（文化条目）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID | 主键 |
| name | VARCHAR(128) | 名称 |
| pinyin | VARCHAR(128) | 拼音 |
| category | ENUM | 分类 |
| rarity | ENUM | 稀有度 |
| origin | VARCHAR(255) | 发源地 |
| material | VARCHAR(255) | 材质 |
| symbolism | VARCHAR(255) | 象征意义 |
| description | TEXT | 详细介绍 |
| image_url | VARCHAR(512) | 图片 |
| audio_url | VARCHAR(512) | 音频 |
| is_published | BOOLEAN | 是否发布 |
| sort_order | INT | 排序 |

### 3.6 wardrobe_item（衣橱道具）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID | 主键 |
| name | VARCHAR(128) | 名称 |
| category | ENUM | 分类 |
| rarity | ENUM | 稀有度 |
| description | VARCHAR(512) | 描述 |
| image_url | VARCHAR(512) | 图片 |
| total_fragments | INT | 合成所需碎片 |

### 3.7 achievement（成就）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID | 主键 |
| name | VARCHAR(128) | 名称 |
| description | VARCHAR(512) | 描述 |
| icon_url | VARCHAR(512) | 图标 |
| unlock_condition | VARCHAR(255) | 解锁条件 |

### 3.8 用户关联表

- `user_explore_progress`: 用户节点进度
- `user_collection`: 用户收集的文化条目
- `user_wardrobe`: 用户拥有的衣橱道具及碎片数
- `user_achievement`: 用户获得的成就

## 4. 枚举定义

### CulturalCategory

- `clothing` 服饰
- `pattern` 纹样
- `music` 音乐
- `cuisine` 饮食
- `craft` 工艺

### Rarity

- `common` 普通
- `rare` 稀有
- `legendary` 传世

### WardrobeCategory

- `clothes` 服饰
- `headwear` 头饰
- `accessories` 配饰
- `skins` 皮肤
